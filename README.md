Registration Form

A simple and responsive registration form built using HTML, CSS, and JavaScript. This project validates user inputs and displays a success popup when the form is submitted with valid details.

Features

* First name and last name validation
* Email format validation
* Password validation (minimum 6 characters)
* Real-time form validation as users type
* Submit button enabled only when all fields are valid
* Success popup after successful form submission
* Continue button to close the success popup
* Responsive design for different screen sizes

Technologies Used

* HTML5 – Structure of the registration form
* CSS3 – Styling, layout, and responsive design
* JavaScript – Form validation, event handling, and popup functionality

Validation Rules

* First Name: Cannot be empty.
* Last Name: Cannot be empty.
* Email: Must follow a basic valid email format.
* Password: Must contain at least 6 characters.

What I Learned

* Selecting HTML elements using JavaScript
* Using addEventListener() to handle user interactions
* Validating form inputs using conditions and regular expressions
* Enabling and disabling buttons dynamically
* Preventing default form submission using event.preventDefault()
* Displaying and hiding a success popup using JavaScript and CSS
